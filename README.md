# 화면설계서

화면 이미지 위에 번호 마커를 찍고, 번호별 기능 설명과 변경 이력, 화면 흐름도를 웹에서 함께 관리하는 도구입니다.
로그인은 없고, 처음 접속할 때 입력한 이름이 작성자와 변경 이력에 기록됩니다.

## 설치

Node.js 22 이상이 필요합니다.

```
npm install
```

## 실행

### 평소 사용(운영)

```
npm run build
npm start
```

서버를 켜면 콘솔에 접속 주소가 표시됩니다.

```
화면설계서 서버 실행 중: http://localhost:4300
  팀원 접속 주소: http://192.168.x.x:4300
```

팀원들은 `팀원 접속 주소`로 접속하면 됩니다. 포트를 바꾸려면 `PORT` 환경변수를 지정하세요(PowerShell: `$env:PORT=8080; npm start`).

### 개발 모드

```
npm run dev
```

이 모드에서는 화면이 http://localhost:5173 에서 열리고, 코드를 고치면 바로 반영됩니다.

## 팀원이 접속하지 못할 때 (Windows 방화벽)

관리자 PowerShell에서 한 번만 실행하세요.

```
New-NetFirewallRule -DisplayName "화면설계서" -Direction Inbound -Protocol TCP -LocalPort 4300 -Action Allow -Profile Domain,Private
```

## 사용법

1. 프로젝트를 만들고 **+ 새 화면**을 누릅니다.
2. 편집 화면에서 캡처한 이미지를 **Ctrl+V**로 붙여넣습니다. 끌어다 놓거나 파일을 선택해도 됩니다.
3. 이미지를 클릭하면 번호 마커와 설명 행이 함께 생깁니다. 마커는 드래그해서 옮길 수 있습니다.
   - `⌖` 버튼: 이미지에서 해당 행의 마커 위치를 다시 지정합니다.
   - `↑ ↓` 버튼: 행 순서를 바꾸며, 번호는 자동으로 다시 매겨집니다.
4. **저장**할 때 버전과 변경 내용을 입력하면 변경 이력에 기록됩니다.
5. 저장하기 전에 다른 사람이 같은 화면을 먼저 저장했다면 경고가 뜹니다. 최신 내용을 불러올지, 내 내용으로 덮어쓸지 고르세요.
6. **화면 흐름도**에서 화면 사이를 연결선으로 이어 이동 관계를 그립니다.

## 내보내기 (프로젝트 화면 오른쪽 위)

- **Excel**: `.xlsx` 파일을 바로 내려받습니다.
  - 첫 시트 `화면목록`에서 화면명을 누르면 해당 화면 시트로 이동합니다.
  - 화면별 시트에는 번호 마커가 그려진 이미지, 기능 설명표, 변경 이력이 들어갑니다.

## 데이터와 백업

모든 데이터는 `data/` 폴더에 JSON 파일과 이미지로 저장됩니다. DB는 쓰지 않습니다.

```
data/projects/<프로젝트ID>/
  project.json        프로젝트 정보
  flow.json           화면 흐름도
  screens/<화면ID>.json
  images/             업로드한 화면 이미지
```

- **백업**: 서버를 끈 뒤 `data/` 폴더를 통째로 복사하면 됩니다.
- **다른 경로에 저장**: `DATA_DIR` 환경변수로 저장 위치를 바꿀 수 있습니다. 공유 드라이브는 지정하지 마세요. 서버 프로세스는 반드시 하나만 띄워야 합니다.
